## 🎯 Overview

Educators and testing organizations spend significant effort manually evaluating the difficulty of examination questions. Misjudged difficulty levels can skew assessment outcomes and inaccurately measure student proficiency.

The **AI-Driven Educational Analytics System** is an end-to-end Machine Learning and Agentic AI pipeline that addresses this challenge in two phases:
1. **Predictive ML Phase:** Automatically predicts question difficulty into Easy, Medium, or Hard tiers using Logistic Regression and TF-IDF.
2. **Agentic Assessment Phase:** Provides deep, intelligent, rubric-based feedback on the construction and pedagogical value of a question using a LangGraph-orchestrated Agent and a FAISS-backed Retrieval-Augmented Generation (RAG) pipeline powered by Google Gemini.

### Problem Statement

> Given a dataset of 5,000 exam questions with associated student performance metrics, build a machine learning model that predicts question difficulty levels. Further, enhance the platform with an Agentic AI workflow to evaluate question structure, clarity, and cognitive complexity based on standard pedagogical guidelines, deploying the entire solution as an interactive web application.

### Key Features

- **Batch Analytics** — Upload a CSV of questions and get instant difficulty predictions for all of them.
- **Single Question Prediction** — Predict difficulty for an individual question with confidence scores.
- **Agentic Qualitative Assessment** — Get AI-generated, structured feedback on question phrasing, distractor quality, and cognitive level using LangGraph and Gemini.
- **Rich Visualizations** — 7 interactive charts in the web app + 14 model performance plots in the notebook.
- **LaTeX Project Report** — Autogenerated comprehensive LaTeX documentation.

## 🤖 Agentic AI & RAG

To provide qualitative insights beyond just a numeric difficulty prediction, we introduced an Agentic Workflow using **LangGraph** and **Google Gemini**.

### RAG Pipeline (Retrieval-Augmented Generation)
- **Knowledge Base:** `data/pedagogy_guidelines.txt`
- **Embeddings:** HuggingFace `all-MiniLM-L6-v2`
- **Vector Store:** Local FAISS index. Captures standard pedagogical rules (e.g., avoiding double negatives, ensuring plausible distractors).

### LangGraph Workflow
The agent manages state transitions iteratively. 
1. **Retrieve Node:** Fetches the top 2 semantic chunks from FAISS based on the current question text.
2. **Generate Node:** Passes the question, retrieved context, and previous ML prediction to Gemini 2.5 Flash.
3. **Structured Output:** Forces the LLM to reply strictly according to a Pydantic Schema (`AssessmentReport`), guaranteeing a structured JSON comprising `construct_feedback`, `cognitive_level`, `distractor_analysis`, and `improvement_suggestions`.

## 🧠 Model

### Pipeline Overview
A single **scikit-learn Pipeline** combining text and numerical features:

| Stage | Component | Details |
|-------|-----------|---------|
| **Text Features** | `TfidfVectorizer` | Converts `question_text` into 3,000 TF-IDF features |
| **Numerical Features** | `StandardScaler` | Normalizes `average_score`, `correct_rate`, `score_variance` |
| **Classifier** | `LogisticRegression` | Multi-class classification with `max_iter=1000` |

## 🕹️ Application

The Streamlit app (`app.py`) provides **three tabs**:

### 1. Batch Analytics
Upload a CSV file containing exam questions and instantly receive distributions, scatter plots, feature average comparisons, and downloadable metrics.

### 2. Single Question Prediction
Enter a question's text and metrics to get the predicted difficulty badge and probability distributions. 

### 3. Agentic Qualitative Assessment (NEW)
Analyze individual questions deeply. It takes the text and the predicted difficulty to generate rich constructive feedback based on the pedagogical RAG knowledge base.

## 🚦 Limitations

- **Language:** Optimized for English-language questions only.
- **Post-Exam Features:** The ML model requires post-exam statistics (average score, correct rate).
- **No Visual Understanding:** Cannot interpret images, diagrams, or graphs embedded in questions.
